# Slides de la presentación final

Requisitos en la sección 4 de [docs/10_entrega_final.md](../../../docs/10_entrega_final.md). Se
construye al final (DOC-10), cuando existan el `DESIGN.md` y las referencias de diseño.

- `index.html`: las slides, máximo 10, siguiendo las secciones del documento.
- **Controles:** flechas para avanzar y retroceder, `p` para pantalla completa y `o` para la vista
  general. Transiciones entre slides.
- `generar_pdf.sh`: genera la versión PDF que se sube a Canvas.
